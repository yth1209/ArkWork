## 문서 사용 규칙

- ArkWork 개발 변경은 사용자 지시에 따라 검증 후 main에 직접 커밋·push한다. 제품이 대상 저장소에 생성하는 명세·구현 PR 및 사람 승인 정책은 별도이며, 개발 커밋은 외부 배포·유료 실행 권한을 부여하지 않는다.
- 이 문서의 기본안은 구현 순서를 정하기 위한 제안이다. 승인 전에는 합의된 운영 정책이라고 표현하지 않는다.
- 기능별 후속 작업은 `specs/<work-slug>/PRODUCT.md`, `TECH.md`에 변경 범위와 검증 조건을 기록하고 이 기획안에 연결한다.
- 모델·런타임 공급자는 실제 API 계약, 비용과 기능을 확인한 뒤 선정한다. 현재 Codex 채팅을 서비스의 상시 실행 API로 간주하지 않는다.
- 문서에 작업 결과, 가격, 테스트 통과 또는 외부 접속 가능성을 허위로 기록하지 않는다.
